# somark-py

[![Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)
[![PyPI version](https://img.shields.io/pypi/v/somark.svg)](https://pypi.org/project/somark/)

[SoMark](https://somark.ai) 官方 Python SDK 与 CLI 工具。

这个仓库是 SoMark SDK + CLI 统一规范的 Python 实现。JavaScript/TypeScript 实现在 [`somark-js`](https://github.com/SoMarkAI/somark-js)。同一个产品目标，两种语言生态。

## 安装

```bash
pip install somark
```

## 文档

官方文档请阅读：[docs.somark.tech/documentation](https://docs.somark.tech/open-source-tools)。

认证、CLI、SDK 示例、异步任务、本地预览、PDF 工具、API 参数和错误处理都在那里。README 只保留入口信息，避免长成另一份更难维护的文档。

## 环境要求

- Python 3.10+
- 远程解析和用量查询需要 SoMark API Key
- 本地 PDF 工具与 SoMarkDown 预览不需要 API Key
